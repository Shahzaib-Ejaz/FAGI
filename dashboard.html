Methods & notation

Evaluation protocol

CICIDS2017 contains 2,520,798 cleaned flows; the benchmark uses a stratified sample of 56,276, 5-fold CV × 3 seeds. Each training fold is split into a private set (22,510 flows, protected by DP-SGD) and a public reference pool (22,510 flows) that supplies graph neighbors; 11,256 flows test each fold. 2,000 malicious test flows per fold are attacked; benign flows are unperturbed. The worst case counts a flow as detected only if it survives every attack. Ablation and privacy results are reported for seed 0. Synthetic and federated experiments retain their separately reported settings.

Metric notation

ε denotes the attack perturbation budget; εDP denotes the differential privacy budget. FPR is the false-positive rate; TPR is the true-positive rate. MIA denotes membership inference attack. A dash means no privacy budget is reported. A matched false-positive rate means each model's decision threshold is set so that a fixed share of benign flows is flagged, which makes models comparable at one operating point. Numerical precision and uncertainty are retained from the results file.
