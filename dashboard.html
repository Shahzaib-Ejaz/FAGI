Running experiments locally

  1. Install dependencies: pip install -r requirements.txt
  2. Download CICIDS2017 Friday subset into data/cicids2017/ — see data/README.md
  3. Generate synthetic dataset: python data/synthetic/generator.py
  4. Run primary adversarial experiment: python experiments/exp3_adversarial_robustness.py
  5. Run full ablation: python experiments/ablation.py
  6. Results write to experiments/results/*.json — refresh this page to visualise them
  7. Run test suite: pytest tests/ -v — all 34 tests should pass
