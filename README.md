# FAGI — Federated Adversarial Graph Intelligence

Code, data loaders, experiments and results for the paper *FAGI: Measuring the Costs of Adversarial Training, Edge Filtering, and Differential Privacy in Graph-Based Threat Detection* (Shahzaib Ejaz, North American University).

FAGI combines four components and measures what each one costs and buys:

| Component | What it does | Where |
|---|---|---|
| Graph construction | API sessions → 12-endpoint call graphs; CICIDS2017 flows → k-NN ego graphs over a reference pool | `fagi/graph/`, `data/cicids2017.py` |
| Detector | 2-layer GraphSAGE (64/32, mean aggregation), linear head | `fagi/model/dense.py` |
| Robustness | GNNGuard-style edge pruning (cosine τ = 0.15) and PGD adversarial training (L∞, K = 10) | `fagi/model/dense.py`, `fagi/training.py` |
| Privacy | DP-SGD: per-example clipping, Gaussian noise, Poisson sampling, Rényi-DP accounting (Opacus); FedAvg across organizations | `fagi/privacy/dp_sgd.py`, `experiments/exp4_federated.py` |

All results in the paper are in [`experiments/results/paper_results.json`](experiments/results/paper_results.json) and summarized in [`dashboard.html`](dashboard.html). Both are generated by scripts; nothing is typed in by hand.

## Installation

```bash
git clone https://github.com/Shahzaib-Ejaz/FAGI.git
cd FAGI
pip install -r requirements.txt     # or requirements-lock.txt for the exact versions used
pip install -e .
python -m pytest -q                 # 64 tests
```

## Quick start

```python
import sys; sys.path.insert(0, "data/synthetic")
from generator import generate_dataset
from fagi import FAGIDetector

sessions = generate_dataset(seed=1)
det = FAGIDetector(dp_sigma=1.1, dp_clip_norm=1.0, dp_delta=1e-6, pgd_epsilon=0.1)
det.fit(sessions, epochs=30)          # prints the computed epsilon
print(det.epsilon)                    # computed by the RDP accountant, not a setting
pred = det.predict(sessions, adversarial=True)
```

The privacy budget is an output, not an input: `FAGIDetector` takes the noise multiplier σ, clip norm and δ, and reports the ε that the accountant computes for the sampling rate and number of steps actually used.

## Reproducing the paper

```bash
bash scripts/run_all.sh
```

This regenerates both synthetic datasets, runs every experiment, writes `experiments/results/*.json`, builds `paper_results.json`, the figures in `figures/`, and `dashboard.html`. Expected runtime is about 7 hours on a 2-core CPU. CICIDS2017 models are cached per (model, fold, seed) under `experiments/results/cache/`, keyed by a hash of the configuration and the core source files, so an interrupted run resumes where it stopped.

| Script | What it produces |
|---|---|
| `experiments/cicids_compute.py` | Trains and attacks every CICIDS2017 model (cached) |
| `experiments/exp1_cicids_benchmark.py` | Clean accuracy, FPR, per-class recall with Wilson intervals, worst-case attack recall |
| `experiments/exp3_adversarial_robustness.py` | Attack-budget sweep, per-attack breakdown, 100-step check; random edge injection on synthetic data |
| `experiments/ablation.py` | Component ablation, σ sweep (privacy–utility), membership inference with an overfit positive control |
| `experiments/exp2_api_native.py` | Synthetic API sessions: all attacks, lateral movement, SQL injection; payload-feature ablation |
| `experiments/exp4_federated.py` | Held-out organization, FedAvg with and without client-side DP-SGD, ε-matched centralized DP, membership inference |

### Evaluation protocol in brief

* **CICIDS2017**: all 8 day files, cleaned (non-finite rows, exact duplicates, constant and duplicated columns removed; mis-encoded Web Attack labels fixed), then a stratified sample of up to 3,000 flows per attack label plus an equal number of benign flows. 5-fold CV stratified on the original label, 3 seeds per fold. Each training fold is split into a **private training set** (what DP protects) and a **reference pool** that supplies graph neighbors at training and inference time; no private record ever appears in another record's graph.
* **Attacks** target malicious flows only. Graph models face PGD on a fixed neighborhood, PGD followed by neighbor re-retrieval, an adaptive PGD that re-retrieves neighbors at every step, and a nearest-benign mimicry attack; flat models face white-box PGD and mimicry; the random forest and k-NN face transfer (from the MLP) and mimicry. A flow counts as detected only if it survives every attack run against that model.
* **Privacy**: δ = 10⁻⁶. Hyperparameters were fixed in advance and not tuned on the evaluation data.
* **Synthetic API sessions**: `data/synthetic/generator.py` (original) and `--difficulty hard`, where some benign users send admin, export or SQL-like requests and half of attack calls carry ordinary payloads. Features use a fixed log(1 + x) transform, so no statistics are fit on private or test data.

## Datasets

**CICIDS2017** — download `MachineLearningCSV.zip` from the [Canadian Institute for Cybersecurity](https://www.unb.ca/cic/datasets/ids-2017.html) and extract the eight CSV files into `data/cicids2017/`. See [`data/README.md`](data/README.md) for the expected files, checksums and the cleaning steps.

**Synthetic API sessions** — `python data/synthetic/generator.py` writes `data/synthetic/sessions_final.json` (seed 42, 4,000 sessions, 5 organizations); add `--difficulty hard --output data/synthetic/sessions_hard.json` for the hard variant.

## Repository structure

```
fagi/
  model/dense.py        dense GraphSAGE, GNNGuard filter, PGD (used by all experiments)
  training.py           training loop: plain, PGD, DP-SGD; seeded and reproducible
  privacy/dp_sgd.py     DP-SGD optimizer and RDP accountant
  graph/                API-session graph construction (sparse and dense)
  federated/server.py   FedAvg aggregation
  detector.py           FAGIDetector high-level API
  model/gnn.py, model/pgd.py, model/gnnguard.py, federated/client.py, privacy/mvg_dp.py
                        legacy PyTorch Geometric reference code, kept for the tests; not used by the
                        experiments. MVGMechanism.clip_and_noise clips the aggregate gradient and is
                        NOT differentially private.
data/
  cicids2017.py         CICIDS2017 loader, cleaning, sampling, ego-graph construction
  synthetic/generator.py
experiments/            experiment scripts, shared harness, results/
scripts/                run_all.sh, build_results.py, generate_figures.py, build_dashboard.py
tests/
```

## Changes from the first version of this repository

The first version reported results (for example 74.4% vs 67.2% under PGD, ε = 2.0, 78.6% membership-inference success) that could not be reproduced from the code: the CICIDS2017 loader was missing, the privacy noise in the experiment scripts was σ ≈ 0.004 rather than 1.1, ε was asserted rather than computed, and the "LLM" payload feature was a keyword count. All results were regenerated from scratch with the code in this repository. The keyword payload score is described as such; the DistilBERT embedder in `fagi/utils/embeddings.py` is not used by any experiment.
